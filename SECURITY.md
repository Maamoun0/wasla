# Security Policy

## Supported Versions

Currently, only the latest `main` branch is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| `1.x.x` | :white_check_mark: |
| `< 1.0` | :x:                |

## Reporting a Vulnerability

Please **DO NOT** report security vulnerabilities via public GitHub issues. 

Instead, report them via email to `security@wasla.dev`. We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If you have not received a reply within 48 hours, please reach out again.
