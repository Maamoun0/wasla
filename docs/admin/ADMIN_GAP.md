# لوحة الأدمن: إيه اللي بتتحكم فيه وإيه اللي ناقص

تقرير بس، ومفيش كود. اتعمل من الكود في `frontend/admin` و`supabase/migrations` يوم 2026-11-03.

**الأحجام:**
- **S:** نص يوم أو أقل.
- **M:** يوم أو يومين.
- **L:** من 3 لـ 5 أيام.

**الرموز:**
- ✅ اللوحة بتعرضه وبتتحكم فيه.
- 👁 بتعرضه بس.
- ❌ مش موجود في اللوحة.

## 1. الموجود النهارده
| الصفحة | بتعمل إيه | مين يدخلها |
|---|---|---|
| الرئيسية | 5 أرقام: عدد المستخدمين، والإعلانات اللي مستنية مراجعة، والإعلانات النشطة، والبلاغات المفتوحة، ومجموع الإيرادات المكتملة | admin، moderator |
| مراجعة الإعلانات | طابور الإعلانات `pending` ومعاها مستوى الخطورة وملاحظات الـ AI. قبول، أو رفض بسبب (`moderate_ad`) | admin، moderator |
| توثيق الهوية | الطلبات، والصور برابط مؤقت 5 دقائق بعد MFA. قبول ورفض (`moderate_kyc`) | admin، moderator |
| البلاغات | قائمة البلاغات. حل أو تجاهل مع ملاحظة (`handle_report`) | admin، moderator |
| المستخدمين | قائمة، وصفحة لكل مستخدم فيها `user_activity_log`. تفعيل، وإيقاف، وحظر، ومعاهم إنهاء الجلسات | admin، moderator |
| الباقات والأسعار | تعديل سعر ومدة وتفعيل `payment_packages` | admin |
| الإعدادات | 5 مفاتيح بس: `enable_boost_feature`، `ai_moderation_enabled`، `enable_kyc_verification`، `maintenance_mode`، `min_trust_score_to_post` | admin |
| تسجيل الخروج | بيعمل signOut | الكل |

كل تعديل من اللوحة بيتسجّل في `audit_logs`.

| `ai_moderation_daily_limit` | ❌ |

| `boost_*` (6 مفاتيح) و`platform_currency` | ❌. محتاجين مراجعة: الأسعار الحقيقية في `payment_packages` |

### العمليات
| العملية | الحالة |
|---|---|
| 10 مهام cron (`expire-ads`، `dispatch-notifications`، `purge-*`، …) | ❌. مفيش آخر تشغيل ولا فشل ولا تشغيل يدوي |
| دالة `health` | ❌. موجودة بس مش ظاهرة في اللوحة |
