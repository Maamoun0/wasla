# استراتيجية تجربة المستخدم (UX Strategy) — منصة "وصلة" (Wasla)

## 1. شخصيات المستخدمين (User Personas)

### الشخصية الأولى: "عم أحمد" (الحرفي / المعلن العادي)
*   **الوصف:** سباك محترف في المعادي، 45 عاماً، يستخدم الهاتف بشكل أساسي للتواصل مع الزبائن.
*   **الأهداف:** زيادة عدد "الشغلانات" اليومية، بناء سمعة طيبة (Trust) تجذب زبائن جدد.
*   **نقاط الألم:** صعوبة كتابة تفاصيل الإعلان، الخوف من النصب أو عدم الجدية، لا يملك ميزانية كبيرة للإعلانات الممولة.
*   **السلوك:** يفضل استخدام الصور المباشرة لشغله، يحب التواصل عبر واتساب، يثق في "شارة التوثيق" جداً.

### الشخصية الثانية: "سارة" (الباحثة عن صفقات / سلع)
*   **الوصف:** ربة منزل أو موظفة شابة، 28 عاماً، تبحث عن توفير المال عبر شراء سلع مستعملة أو خدمات قريبة منها.
*   **الأهداف:** إيجاد أفضل سعر في منطقتها، التأكد من مصداقية البائع قبل النزول لمقابلته.
*   **نقاط الألم:** الإعلانات الوهمية أو المكررة، البعد الجغرافي (مشقة المواصلات)، ضياع العروض الجيدة بسرعة.
*   **السلوك:** تستخدم الفلاتر بكثافة (أرخص سعر، الأقرب)، تضع الإعلانات في المفضلة، تفضل رؤية تقييمات الآخرين.

### الشخصية الثالثة: "استاذ إبراهيم" (صاحب عمل / مستخدم Business)
*   **الوصف:** صاحب معرض سيارات أو مكتب عقارات صغير، 38 عاماً.
*   **الأهداف:** إدارة عدد كبير من الإعلانات، تتبع المشاهدات والاتصالات، التميز عن المنافسين.
*   **نقاط الألم:** ضياع إعلاناته وسط آلاف الإعلانات الجديدة، الحاجة لتحليلات دقيقة لمعرفة فعالية إعلانه.
*   **السلوك:** يستخدم الـ Boost (Featured) بشكل دوري، يتابع لوحة التحكم (Admin Panel) يومياً، يهمه "شارة الموثّق" لرفع سعر بضاعته.

## 2. رحلة المستخدم (User Journey Map)

### مرحلة الاكتشاف (Discovery)
*   **الفعل:** المستخدم يفتح التطبيق كـ "زائر".
*   **التجربة:** تصفح سريع لأحدث الإعلانات في منطقته الجغرافية الحالية (GPS).
*   **UX Goal:** إبهار المستخدم بتنوع المحتوى وقربه منه لتحفيزه على التسجيل.

### مرحلة الثقة (Trust & Verification)
*   **الفعل:** التسجيل عبر OTP SMS والبدء في إجراءات "توثيق الرقم القومي".
*   **التجربة:** واجهات واضحة تشرح فائدة التوثيق (زيادة الثقة + شارة ✓).
*   **UX Goal:** تحويل المستخدم من "عابر" إلى "موثوق".

### مرحلة المعاملة (The Core Action)
*   **الفعل:** نشر إعلان أو التواصل مع معلن.
*   **التجربة:** تدفق نشر بسيط (خطوة بخطوة)، أزرار تواصل ضخمة (اتصال/واتساب).
*   **UX Goal:** تقليل الجهد (Friction) إلى أقصى حد.

## 3. خريطة الشاشات الكاملة (Screen Map)

1.  **الرئيسية (Home):** بحث، أقسام، إعلانات مميزة، إعلانات بالقرب منك.
2.  **الأقسام (Categories):** قائمة فرعية لكل قسم (مثلاً: خدمات -> سباكة/كهرباء).
3.  **نشر إعلان (Post Ad):** اختيار القسم، الصور، التفاصيل، السعر، الموقع، خيارات الـ Boost.
4.  **المفاوضات/التواصل (Inbox/Logs):** سجل المكالمات داخل التطبيق، المفضلة، البحوث المحفوظة.
5.  **الملف الشخصي (Profile):** إعلاناتي، إحصائيات، إعدادات، التوثيق، الرصيد (Credits).

---

## 4. تفصيل الـ Flows الرئيسية

### Flow 1: Onboarding & Auth
*   Splash Screen -> Intro Slides -> Phone Entry -> OTP -> Basic Info (City Selection).

### Flow 2: Posting an Ad (نشر إعلان)
*   Select Category -> Upload Media (Drag & Drop) -> Fill Dynamic Fields (based on category) -> Set Price & Location -> Boost Selection (Skip or Pay).

### Flow 3: Search & Discovery (البحث)
*   Keyword Entry -> Filter by City/District -> Filter by Price Range -> Filter by "Verified Only" -> Map View toggle.

### Flow 4: Communication (تواصل)
*   Ad Detail Screen -> Floating Action Buttons (Call / WhatsApp) -> Confirmation Dialog -> Log contact event (Internal Logs).

### Flow 5: Boosting (Paymob Flow)
*   Select Ad -> Choose Boost Type (Featured/Urgent) -> Payment Method Selection (Vodafone Cash/Card/Fawry) -> Paymob Overlay -> Success Screen.

### Flow 6: Watchlist (الـ Watchlist)
*   Save Search Query -> Enable Instant Notifications -> Notification Received -> Redirect to New Matching Ad.

## 5. هيكل الـ Bottom Navigation (5 Tabs)

1.  **الرئيسية (Home):** أيقونة 🏠 - اكتشاف كل شيء.
2.  **أقسام (Categories):** أيقونة 🗂️ - وصول سريع للتصنيفات.
3.  **أضف إعلان (Sell):** أيقونة ➕ (مركزية ومميزة بلون Gold) - زر الفعل الأساسي.
4.  **المفضلة (Favorites):** أيقونة ♡ - الوصول للبحوث والإعلانات المحفوظة.
5.  **حسابي (Profile):** أيقونة 👤 - إدارة الإعلانات والتوثيق.

## 6. ملاحظات UX للسوق المصري

*   **Offline-First Mentality:** المصريين يفضلون "الاتصال الهاتفي" المباشر أكثر من الشات داخل التطبيق، لذا سجل المكالمات (Contact Logs) ميزة جوهرية.
*   **Trust is Currency:** التركيز على شارة "موثّق ✓" والرقم القومي يعالج أزمة النصب الشهيرة في المنصات المنافسة.
*   **Low Bandwidth Friendly:** استخدام صور مضغوطة (WebP) وسرعة تحميل عالية لأن باقات الإنترنت قد تكون محدودة.
*   **Egyptian Dialect (Optional):** استخدام لغة عربية بيضاء قريبة من اللهجة المصرية في "رسائل النجاح" لزيادة الود والقرب (أهلاً بك، إعلانك نور، الخ).
*   **Social Proof:** إظهار عدد المشاهدات وعدد الأشخاص الذين تواصلوا مع المعلن لخلق "Fomo" (الخوف من ضياع الفرصة).
